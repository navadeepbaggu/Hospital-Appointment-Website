
# City Care Hospital – Accessible Appointment Management Website

## Project Overview
City Care Hospital is a hospital appointment management webpage developed using HTML5, CSS and JavaScript.

This project focuses on improving webpage structure, accessibility and patient appointment form validation.

## Objectives
- Refactor the webpage using HTML5 semantic elements.
- Improve accessibility for screen-reader users.
- Provide proper labels and input types for form fields.
- Implement client-side form validation.
- Test accessibility using Google Lighthouse.
- Manage project changes using Git and GitHub.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Google Chrome Lighthouse
- Windows Narrator
- Git and GitHub

## Features
- Semantic HTML5 webpage structure.
- Hospital services and doctor information.
- Patient appointment registration form.
- Required field validation.
- Phone number validation.
- Email validation.
- Date validation.
- Keyboard navigation support.
- Accessible form error messages.
- Screen-reader testing.

## Accessibility Testing

### Lighthouse Audit

| Version | Accessibility Score |
|---|---:|
| Original webpage | 100/100 |
| Updated webpage | 100/100 |

Both versions achieved a Lighthouse Accessibility score of 100.

### Screen Reader Testing
Screen-reader testing is performed using Windows Narrator with Google Chrome.

The following areas are tested:
- Page title and headings.
- Navigation links.
- Form labels.
- Keyboard navigation.
- Form validation messages.

## Git Workflow
A separate feature branch is created to manage the accessibility improvements.

Planned workflow:
1. Create a feature branch.
2. Commit the updated HTML and related files.
3. Push the branch to GitHub.
4. Create a Pull Request.

## Conclusion
The project demonstrates the use of semantic HTML5, accessible form design, client-side validation, accessibility testing and Git-based version control for a hospital appointment management website.
